## Exam overview shown on the course page

The exam is intended for people who understand core agentic AI concepts, event-driven architecture, and the ADLC and can explain how Solace Agent Mesh applies those concepts as an agent development and runtime platform. The listed primary components are the Event Broker, Orchestrator, Agents, and Entrypoints.

The page says the certification validates the learner's ability to explain the six ADLC stages; distinguish Orchestrator-based and Workflow-based coordination; identify workflow coordination patterns and node types; explain event-driven design compared with polling, batch processing, and custom point-to-point integrations; and apply cost, governance, security, and repeatability considerations.

## Exam conditions

The course page describes an open-book, non-proctored exam with 30 questions drawn from a larger question bank, a 90-minute duration, multiple-choice, multiple-response, and matching formats, and a passing score of 70%. It says all questions must be attempted and guessing carries no penalty. Results are delivered immediately, with a certificate of achievement after passing.
