## Notes

### The Rise of Intelligent Systems

The lesson opens with Ali Pourshahid's statement that an Event Mesh can provide business value and competitive differentiation in the AI-driven economy by combining current enterprise context, AI, and real-time data.

The lesson frames enterprise AI as an opportunity, especially with large language models, but says integration into existing business processes has challenges. Four tabs list these challenges:

- **Lack of real-time information:** Sophisticated LLMs need current contextual data, which they do not inherently have; RAG is intended to help, but not all RAG databases are updated in real time as events occur.
- **Scalability concerns:** AI solutions that work in experiments may not scale to production-ready enterprise use.
- **Distribution across environments:** Enterprise data spans applications and on-premises, edge, and cloud infrastructure. Hyperscaler solutions that require moving data to their services may be unsuitable, and organizational changes continually create the need for new data feeds into AI systems.
- **Ramifications of agentic AI:** Wider use of agents raises architectural questions about providing context to agents and enabling agent-to-agent communication.

The lesson says that real-time AI projects need situational context. iPaaS and integration technology alone are not enough; a data distribution layer such as an event mesh is needed to deliver large volumes of targeted information in real time. Real-time data flow, transformation, and processing can keep models current, let them respond and trigger actions such as updating RAG databases, reduce polling and batch processing, lower latency, and let AI models enrich, transform, and publish events across the organization.

Six expandable benefit cards give examples. **AI adoption:** an event mesh quickly integrates AI and analytics into existing processes, reuses investments across on-premises, edge, and cloud workloads, and supports best-of-breed cloud services; a manufacturer combines sensor data, historical records, and schedules for real-time predictive maintenance. **Customer experiences:** current, comprehensive data supports personalized experiences; a bank combines transaction history, portfolios, market data, summarized news, social trends, and sentiment for advisor and self-service experiences. **Decision-making:** contextual real-time data helps people and agents make faster, more relevant decisions and avoid outdated information; a retailer uses sales, weather, and social trends for inventory decisions. **Costs and efficiency:** simpler integration, less duplication, better resource use, lower integration and maintenance costs, improved data quality, faster time-to-market, and efficient scaling; a logistics company combines fleet, weather, news, and order data to optimize routes. **Innovation:** rapid, cost-effective AI product development; an airline uses real-time profiles, travel history, prices, and destination information for a personalized GenAI travel assistant. **Future-proofing:** flexible scaling and adoption of new technologies without major overhauls; an insurer adds a new AI risk model without affecting other system components.

The next screen says an event mesh can help organizations advance in the AI era while retaining investments in applications and middleware. It describes real-time event context as a source of innovation, faster time-to-market, cost efficiency, and long-term competitiveness.
