# Event-Driven Integration with Solace Platform

## Course record

The Academy identifies this as mandatory English e-learning in the Solace Certified Integration Associate Path. Course ID: E-6VX680. Estimated duration: 4 hours. The course page describes it as a compilation of sources and information to prepare learners for the Solace Certified Integration Associate exam. It is intended for people with knowledge of Event-Driven Architecture (EDA) and Event-Driven Integration who can apply that knowledge to event-enable an organization’s integration infrastructure with Solace Platform.

The course overview lists these objectives: how Solace is re-thinking integration; how Event-Driven Integration differs from Event-Driven Architecture; integration patterns; event-driven Micro-Integrations; event-driven iPaaS basics and broker and connector options; tooling that supports Event-Driven Integration; and the business impact of introducing AI to an event mesh.
