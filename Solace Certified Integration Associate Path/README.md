## Certification path context

The learning-plan overview says the full certification path consists of Foundations of Event Driven Architecture, the Solace Certified Event Driven Architecture Practitioner Exam (SCEDAP), Event Driven Integration with Solace Platform, and the Solace Certified Integration Associate Exam (SCIA). It states that SCEDAP is a prerequisite and that SCIA remains locked until prerequisites are complete, unless the prerequisite was completed separately and Academy unlocks it automatically. The learning-plan page lists only the final two items as its courses.

The learning-plan page lists a $500 USD cost for the certification path and recommends the one-year Individual Digital-Only Learning Subscription. No purchase or subscription action was taken.
