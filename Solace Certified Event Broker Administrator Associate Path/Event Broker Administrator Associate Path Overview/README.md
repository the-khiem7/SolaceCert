## Learning plan context

The original path overview note recorded the objectives and audience below. Its one-of-four completion count reflects the status at the time of that capture; use the current screenshot status above.

The self-paced certification introduces operational management of Solace products and configuration and administration of features used by applications that use Solace messaging. The certification applies to software and hardware event brokers; the labs and configurations focus on software brokers.

The path objectives shown on the learning plan page were to understand Solace product features and administration; configure role-based administration for Solace Message Brokers; configure guaranteed delivery and exchange patterns for applications that cannot tolerate data loss; troubleshoot and monitor Solace products; understand high availability and disaster recovery; connect PubSub+ instances across hybrid cloud or for horizontal scaling; and share data across messaging environments using Solace VPN Bridges.


The course page recommended an annual digital learning subscription over buying this learning plan individually, stating that the subscription provides access to paid Solace Academy content for 12 months at the same price. This was course-page guidance, not an account or purchase action.
