### 2. Solace Essentials Course

Solace Essentials provides foundational concepts for the PubSub+ Platform and includes a guided hands-on activity. Its overview topics are event-driven concepts, Event Portal, event brokers, event management, event monitoring, and event mesh.

### 3. Event Broker Administration

This course helps administrators understand PubSub+ broker features and configuration. It applies to appliance and software brokers; its hands-on activity focuses on software brokers. The listed modules are client authentication and authorization, Solace multitenancy, direct and guaranteed messaging, high availability (HA), data replication (DR), static bridges versus Dynamic Message Routing (DMR), and operational maintenance.

### 4. Certification Exam

The exam has 70–75 multiple-choice questions, a 90-minute time limit, and up to three attempts. A certificate and badge are sent after completion.

### 5. Target Audience

The learning path is intended for engineers, system administrators, and operational staff.
