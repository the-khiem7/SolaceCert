# Welcome!

- **Course:** Solace Essentials
- **Syllabus order:** 01
## Introduction section

## Welcome! - opening

The lesson welcomes learners to Solace Essentials and presents it as a foundation for many Solace technical learning paths, introducing key concepts through hands-on activities.

## Welcome! - course objectives

By the end of the course, learners are expected to explain the PubSub+ Platform and event-driven terminology; model an event-driven architecture (EDA) use case in Event Portal; deploy event brokers; perform basic configuration and administration; and understand basic monitoring and metrics.

## Welcome! - intended learners

The course is for architects, developers, administrators, and others who want to get started with the PubSub+ Platform.

## Welcome! - requirements

The course requirements are a computer running macOS or Windows, Chrome or Firefox, and Docker Desktop. The hands-on labs use the Activity Guide.

## Welcome! - final screen

The lesson closes with “Let’s get started!”
